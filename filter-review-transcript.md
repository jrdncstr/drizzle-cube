# Reviewer demo: read-only dashboard filters

This PR lets viewers filter a read-only dashboard. Previously, the filter controls were hidden.

The filter selection changed, but the charts didn’t update.

Now, changing a filter updates both charts. Viewers can use these controls on read-only dashboards too.

Viewers change existing filter values. Adding or removing filters still requires editing access.
